# 過去の実験と結果

## レイヤー割り当ての比較条件

レイヤー割り当ての比較対象は、頂点 627 件、ハイパーエッジ 383 件、XY 上の重なり 4,431 組を含む現行の入力と、頂点 ID・XY 座標・ハイパーエッジ ID・所属頂点順・重なり集合が一致する保存解である。過去の配置も含め、正則化 `1e-5` と現行の正規化式で二乗目的値を評価した。柱の総長は表示倍率を掛ける前の値。整数解と連続解を比べるときは高さ幅を使い、使用レイヤー数は整数解について記録する。比較対象の保存解はすべて、数値誤差の許容範囲内で重なり制約違反が 0 件だった。 [共通の評価式](../research_overview.md#現行手法と数理定式化)・[評価指標の計算](../solve_layers_dsatur_l1.py#L159)

## ダミーレイヤーで上下順序を探索した実験

DSatur の 39 色から開始し、一時的なダミー層を使ってポリゴンを移動・交換した。候補の上下関係を作り直してから L2 QP を再求解し、目的値が下がる候補を採用した。次の 2 試行は同じ初期目的値 6,182.946 から始まり、いずれも `max_blockers=0`。 [ソルバー](../solve_layers_dummy.py)・[設計と停止条件](../dummy_layers_implementation_plan.md#97-計算予算と停止条件)

| 保存記録 | 探索予算 | 新規 QP 求解／採用 | 最良の二乗目的値 | 柱の総長 | 総経過時間 | 判明している未評価候補 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| `3f04f88` の `dummy_layer_search.summary` | 1,800 秒 | 8／3 | 6,009.834（2.80% 改善） | 8,646.961 | 59,599.8 秒（約 16 時間 33 分） | 187 件 |
| `a8f6311` の `dummy_layer_search.summary` | 3,600 秒 | 15／5 | 5,997.166（3.00% 改善） | 8,635.012 | 3,778.5 秒（約 63 分） | 316 件 |

両試行とも時間予算で停止し、高さ幅は約 38 だった。最初の試行では柱の総長が基準解より約 3.94 増え、QP の再求解だけで 59,476.2 秒かかった。当時の実装では実行中の求解を打ち切る仕組みがなく、1,800 秒の探索予算を大幅に超えた。2 回目も再求解に 3,590.4 秒かかり、候補の評価数が限られた。根付き木方式は、この費用を避けるため候補の整数レイヤーを直接評価する。元記録は各コミットの `layered_hypergraph.json` に残る。

## 根付き木＋焼きなまし法の実験

BFS が作った初期木では、4,431 組のうち 3,447 組が同一レイヤーで重なった。157 手の修復で違反を 0 件にし、空レイヤーを詰めた初期解は 50 層、目的値 11,960.003 だった。どちらの実験も seed 0 から実行し、試行数上限に達して停止した。

| 状態・実行条件 | 二乗目的値 | 使用レイヤー数 | 高さ幅 | 柱の総長 | 総経過時間 |
| --- | ---: | ---: | ---: | ---: | ---: |
| BFS＋修復の初期解 | 11,960.003 | 50 | 49 | 11,658 | — |
| 1,000 試行・上限 20 秒・温度サンプル 4 件 | 4,438.978 | 44 | 43 | 7,568 | 16.532 秒 |
| 20,000 試行・上限 600 秒・温度サンプル 16 件 | 3,493.207 | 44 | 43 | 6,490 | 265.266 秒 |

- 20,000 試行では初期解から目的値が 70.79% 下がり、ここに記録した保存解の中で最小の二乗目的値を得た。1,000 試行の結果と比べて目的値と柱の総長は下がり、レイヤー数はどちらも 44 だった。DSatur＋L2 QP と比べて柱は短く、高さ幅は約 38 から 43 に増えた。現行の目的関数は共有頂点数で重み付けした距離の二乗和を最小化する。使用レイヤー数を抑える効果は個別に検証する。
- 20,000 試行では、修復と木の再構築後に元の状態へ戻った候補が 2,506 件（12.53%）あった。計測した処理時間では候補の評価に 166.1 秒、修復に 35.0 秒、木の再構築に 33.2 秒かかった。近傍操作の比率を調整する実験では、目的値と併せて元の状態に戻った割合と処理時間を確認する。
- 2 試行で試行数と温度サンプル数の両方が変わり、seed は共通の 0 だった。探索法の効果を調べるには、同じ初期解と予算で複数 seed の `greedy` と `anneal` を比較し、`anneal` の温度設定を記録する。BFS と DFS、根の選択、レイヤー数を目的関数や制約に入れる案も今後の検証対象である。 [1,000 試行のレポート](../results/reports/layered_hypergraph_tree_report.json)・[20,000 試行のレポート](../results/reports/layers_hypergraph_report.json)・[実装計画の実験方法](../rooted_tree_layer_assignment_plan.md#12-実験方法と評価指標)

## XY 平面のポリゴン整形・配置の実験

形状は 168 のポリゴン面を評価した。正多角形比は小さいほど正多角形に近い。これらの実験では頂点と所属を保持して XY を変えたため、各実験の前後を比較して形状と交差の変化を確認する。

| 手法・条件 | 平均正多角形比の前後 | 凹面数の前後 | XY の重なり組数の前後 | 経過時間 |
| --- | ---: | ---: | ---: | ---: |
| Clique 初期化の候補、seed 7 | 4.964 → 2.763 | 113 → 93 | 4,431 → 4,818 | 70 秒 |
| `paper` モード、clique 初期化、seed 7、3 サイクル上限 | 4.964 → 3.384 | 113 → 117 | 4,431 → 8,307 | 124.6 秒 |
| `scalable` 初回、二部グラフ初期化、seed 7、各段階 6 サイクル上限 | 4.964 → 2.115 | 113 → 93 | 4,431 → 7,734 | 536.4 秒 |
| 整形後の `arrange`、300 反復・3 周回・形状許容率 0.10 | 2.115 → 2.128 | 93 → 90 | 7,734 → 7,564 | 87.8 秒 |
| 配置調整後の入力に `scalable` を再実行、seed 7 | 2.128 → 2.875 | 90 → 100 | 7,564 → 7,427 | 369.3 秒 |

- Clique 候補は大きな面の凹みが残り、交差が増えたため入力には適用されなかった。`paper` も平均正多角形比は改善したが、凹面と重なり組数は増えた。`scalable` 初回では 30 頂点以上の面の平均比が 13.075 → 1.442、最大の 161 頂点面が 30.040 → 1.897 まで改善した。重なりは 3,303 組増え、交換探索はサイクル上限で停止した。 [Clique 候補](../results/reports/polygon_layout_report_clique.json)・[`paper` のレポート](../results/reports/polygon_paper_report.json)・[`scalable` 初回のレポート](../results/reports/polygon_scalable_report.json)・[形状の詳細](../polygon_layout_reproduction.md)
- `arrange` では共有頂点が 0 個の交差面積合計が 1,222.7624 → 1,181.0707（約 3.41% 減）。平均正多角形比は約 0.64% 悪化し、密集部分の見た目の改善は限定的だった。続く `scalable` の再実行では重なりは減ったが、形状が悪化した出力で原本を上書きしたため、直前の XY をバックアップから復元した。この経緯から、全体平均・交差数に加えて面ごとの形状変化を確認する。 [配置調整レポート](../results/reports/polygon_arrangement_report.json)・[配置調整の比較画像](../results/previews/polygon_arrangement_comparison.png)・[再実行レポート](../results/reports/polygon_layout_report.json)・[復元記録](../results/reports/polygon_shape_recovery_report.json)
- 復元した `original_polygon_arranged.json` を初回整形前と比較すると 137 面が改善、31 面が悪化した。形状比 1.20 以下、凸包面積欠損率 0.02 以下、辺長の変動係数 0.25 以下などの確認用基準をすべて満たしたのは 168 面中 7 面だった。復元した XY での DSatur＋L2 QP は重なり 7,564 組、目的値 18,393.355、制約違反 0 件。旧 `layered_hypergraph_initial.json` と `layered_hypergraph_checkpoint.json` はこの形状を使った初期解である。現行 `original.json` の重なりは 4,431 組なので、この 7,564 組の初期解は別の XY 条件の記録として扱う。 [全件判定レポート](../results/reports/polygon_quality_report.json)・[調整後の XY](../results/layouts/original_polygon_arranged.json)・[復元時のレイヤー検証](../results/reports/polygon_shape_recovery_report.json)
