# esa への実験報告

- 実験終了後、esa の `vdslab` チームの `ゼミ/大学院/dan` カテゴリに、実験 ID ごとにチーム内向けの Markdown 記事を 1 件投稿する。途中で終了した実験では、検証済みの途中結果と残りのケースを記載する。 [投稿先カテゴリ](https://vdslab.esa.io/#path=%2F%E3%82%BC%E3%83%9F%2F%E5%A4%A7%E5%AD%A6%E9%99%A2%2Fdan)
- 記事の題名に実験 ID を含め、本文には目的、比較手法、入力、seed、予算、主要な評価指標と検証結果、終了理由、実行コードと成果物の参照先を記載する。作成できたら URL を当該実験の記録と最終報告に残す。
- 再開時はその実験 ID に対応する記事 URL の記録を確認し、記事があればその URL を使う。投稿後に応答が途切れた場合は投稿状況を「未確認」と記録し、送信し直す前に投稿先で同じ実験 ID の記事の有無を確認する。
- API で投稿する場合は [投稿スクリプト](../../../tools/post_esa_report.py) を使う。スクリプトは `vdslab` の `ゼミ/大学院/dan` に投稿し、認証情報は環境変数 `ESA_ACCESS_TOKEN` または Git の追跡対象外の `.env.esa.local` から読み込む。トークンは `vdslab` チームに限定した PAT v2 の `write:post` を使い、値をチャット、コミット対象のファイル、実行ログ、記事に記載しない。 [ローカルでの設定と実行](../../../README.md#esa-への実験レポート投稿)・[esa のスコープ定義](https://docs.esa.io/posts/555)
- 認証が未設定の場合、または投稿に失敗した場合は、実験結果のディレクトリに記事本文を Markdown で保存し、最終報告に保存先と投稿状況を記載する。
